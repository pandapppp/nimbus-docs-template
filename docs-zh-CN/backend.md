欢迎来到 **Python 后端开发**教程！

Python 后端开发是 Web 开发的核心技能。本教程将从零开始，带你掌握 Python 后端开发的完整技术栈。

## 学习路径

### 🚀 基础篇

- **[FastAPI 入门](/backend/fastapi/)** - 学习 FastAPI 框架基础，快速构建 API
- **[数据库操作](/backend/database/)** - 使用 SQLAlchemy ORM 操作数据库

### 🔒 核心篇

- **[认证授权](/backend/auth/)** - JWT 认证、权限控制和安全防护
- **[缓存和队列](/backend/cache/)** - Redis 缓存和消息队列

### 🐳 进阶篇

- **[Docker 部署](/backend/docker/)** - 使用 Docker 和 Docker Compose 部署应用

## 章节一览

| 章节 | 内容 | 难度 |
| --- | --- | --- |
| FastAPI 入门 | 路由、请求处理、响应模型 | ⭐ |
| 数据库操作 | SQLAlchemy ORM、CRUD、关系查询 | ⭐⭐ |
| 认证授权 | JWT、密码哈希、RBAC 权限 | ⭐⭐⭐ |
| 缓存和队列 | Redis 缓存、消息队列、Celery | ⭐⭐⭐ |
| Docker 部署 | Dockerfile、Compose、Nginx | ⭐⭐⭐ |

## 快速开始

1. **先看[FastAPI 入门](/backend/fastapi/)**，搭建第一个 API
2. **学习[数据库操作](/backend/database/)**，连接数据库
3. **掌握[认证授权](/backend/auth/)**，实现用户登录
4. **使用[缓存和队列](/backend/cache/)**，提升性能
5. **部署上线](/backend/docker/)**，用 Docker 部署到服务器

## 技术栈

| 技术 | 用途 |
| --- | --- |
| **FastAPI** | Web 框架 |
| **SQLAlchemy** | ORM 数据库操作 |
| **PostgreSQL/MySQL** | 关系型数据库 |
| **Redis** | 缓存和消息队列 |
| **JWT** | 认证 |
| **Docker** | 容器化部署 |
| **Nginx** | 反向代理 |
