**Project Zomboid**（僵尸毁灭工程）是一款由 The Indie Stone 开发的**开放世界末日生存模拟游戏**。游戏设定在 1993 年的美国肯塔基州诺克斯县，一场神秘的僵尸疫情爆发，玩家需要在充满丧尸的世界中尽可能长久地生存下去。

## 核心理念

> **"这是你如何死亡的故事。"** —— 游戏的官方标语

Project Zomboid 没有通关条件，没有主线剧情，唯一的结局就是**死亡**。你能做的，只是让这个结局来得更晚一些。

## 游戏特色

| 特色 | 说明 |
| --- | --- |
| **硬核生存** | 饥饿、口渴、疲劳、疾病、心理健康全部需要管理 |
| **真实模拟** | 季节变化、电力/水源断供、食物腐烂、伤口感染 |
| **开放世界** | 整个诺克斯县可自由探索，包含路易斯维尔等城市 |
| **自由建造** | 可以建造、加固、装饰自己的安全屋 |
| **技能成长** | 通过实践学习技能，从烹饪到木工到电气维修 |
| **多人联机** | 支持合作生存，与朋友一起对抗末日 |
| **高度 Mod 支持** | Steam 创意工坊有海量模组 |

## Build 42 主要变化

Build 42 是目前最新的大型更新，带来了：

- **新地图区域**：大量新城镇和地点
- **动物系统**：可饲养家畜
- **新制造系统**：更多工艺和制造选项
- **改进的战斗系统**：新的武器和战斗机制
- **地下区域**：矿洞等地下探索内容

## 适合什么玩家？

- ✅ 喜欢硬核生存游戏的玩家
- ✅ 喜欢慢节奏、高沉浸感的玩家
- ✅ 喜欢自由建造和基地管理的玩家
- ✅ 喜欢和朋友合作生存的玩家
- ❌ 追求快节奏动作的玩家
- ❌ 不喜欢高难度/高惩罚的玩家
