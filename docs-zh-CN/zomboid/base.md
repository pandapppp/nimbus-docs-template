在 Project Zomboid 中，一个好的基地是长期生存的关键。你需要一个**安全、资源丰富、易于防御**的据点。

## 基地选址

### 选址要素

| 要素 | 重要性 | 说明 |
| --- | --- | --- |
| **安全性** | ⭐⭐⭐⭐⭐ | 僵尸刷新率低、入口少 |
| **水源** | ⭐⭐⭐⭐ | 附近有水井或河流 |
| **耕地** | ⭐⭐⭐ | 可以种植食物 |
| **资源** | ⭐⭐⭐ | 附近有商店、仓库 |
| **交通** | ⭐⭐ | 方便外出搜刮 |

### 新手推荐基地

#### 1. 罗斯伍德加油站（推荐）

```
优点：位置适中、有燃料、相对安全
缺点：面积小、防御性一般
坐标：大致在地图中部偏西
```

#### 2. 农场（长期生存首选）

```
优点：远离城市、有耕地、僵尸少
缺点：资源较少、需要长途跋涉
坐标：地图边缘的农场区域
```

#### 3. 路易斯维尔郊区

```
优点：资源极其丰富、建筑多样
缺点：僵尸密度高、前期危险
坐标：地图东北部城市区域
```

## 基础建设

### 木工技能等级

| 等级 | 可建造内容 |
| --- | --- |
| **0 级** | 木板（封窗） |
| **1 级** | 木箱、简易床 |
| **2 级** | 木围栏、木门 |
| **3 级** | 木楼梯、木地板 |
| **4 级** | 雨水收集器、木墙 |
| **5 级** | 高级围栏、加固门 |
| **6+ 级** | 高级建筑、防御工事 |

### 建造材料

| 材料 | 获取方式 | 用途 |
| --- | --- | --- |
| **木板** | 砍树、拆家具 | 基础建材 |
| **钉子** | 搜索五金店 | 连接木板 |
| **锤子** | 搜索工具箱 | 建造工具 |
| **锯子** | 搜索工具箱 | 切割木材 |
| **油漆** | 搜索商店 | 装饰 |

### 第一天改造

1. **封堵所有窗户**：用木板封住（需要木板 + 钉子 + 锤子）
2. **只留一个入口**：便于防御和管理
3. **设置床铺**：恢复体力的关键
4. **放置储物箱**：整理物资

## 防御工事

### 多层防御

```
外围：木围栏 + 陷阱
中层：木墙 + 加固门
内层：紧急逃生路线
```

### 防御设施

| 设施 | 效果 | 建造要求 |
| --- | --- | --- |
| **木围栏** | 阻挡低级僵尸 | 木工 2 级 |
| **铁丝网** | 有效阻挡僵尸 | 需要铁丝网 |
| **噪音陷阱** | 分散僵尸注意力 | 电子零件 |
| **钉板陷阱** | 伤害踩踏的僵尸 | 木板 + 钉子 |
| **篝火陷阱** | 燃烧僵尸 | 木材 + 燃料 |

### 陷阱使用技巧

- **钉板陷阱**：放在入口处，僵尸踩上会受伤
- **噪音陷阱**：放在远处，吸引僵尸离开基地
- **篝火陷阱**：放在僵尸必经之路上，点燃后大范围伤害

## 功能分区

一个好的基地应该有明确的功能分区：

### 生活区

- **卧室**：床、储物柜
- **厨房**：炉灶、冰箱（有电时）、储物箱
- **储藏室**：分类存放物资

### 工作区

- **木工区**：木材、工具
- **制造区**：工作台、材料
- **医疗区**：药品、绷带

### 防御区

- **入口**：加固门、陷阱
- **瞭望点**：观察周围情况
- **逃生路线**：紧急出口

## 资源管理

### 物资分类

| 类别 | 存储位置 | 优先级 |
| --- | --- | --- |
| **食物** | 厨房/冰箱 | ⭐⭐⭐⭐⭐ |
| **医疗** | 医疗区 | ⭐⭐⭐⭐ |
| **武器** | 入口附近 | ⭐⭐⭐⭐ |
| **工具** | 工作区 | ⭐⭐⭐ |
| **材料** | 储藏室 | ⭐⭐ |

### 资源循环

1. **食物**：种植 → 收获 → 烹饪 → 食用
2. **水**：雨水收集器 → 净化 → 饮用
3. **木材**：砍树 → 切割 → 建造
4. **燃料**：搜索加油站 → 发电机 → 电力

## 基地维护

### 日常维护

- **检查防御**：修补损坏的围栏/墙壁
- **清理僵尸**：定期清理基地附近的僵尸
- **补充物资**：外出搜索所需资源
- **种植管理**：浇水、施肥、收获

### 扩建计划

1. **第一周**：基本生存设施
2. **第二周**：防御工事
3. **第三周**：功能分区
4. **第四周**：长期发展设施（耕地、养殖场）

基地建设完成后，下一步是了解[技能系统](/zomboid/skills/)，提升你的生存能力。
