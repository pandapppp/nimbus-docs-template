在 Project Zomboid 中，**战斗是不可避免的**，但**聪明的战斗**比无脑砍杀更重要。

## 战斗基本原则

> **"能跑就跑，能躲就躲，非打不可再打。"**

### 新手战斗三原则

1. **不要同时面对超过 2 个僵尸**
2. **永远保留逃跑的体力**
3. **战斗前确认逃跑路线**

## 近战战斗

### 近战武器推荐

| 武器 | 伤害 | 耐久 | 获取难度 | 推荐度 |
| --- | --- | --- | --- | --- |
| **斧头** | 高 | 高 | 中 | ⭐⭐⭐⭐⭐ |
| **棒球棍** | 中 | 高 | 低 | ⭐⭐⭐⭐ |
| **菜刀** | 中 | 低 | 极低 | ⭐⭐⭐ |
| **锤子** | 中 | 高 | 低 | ⭐⭐⭐⭐ |
| **撬棍** | 中 | 极高 | 中 | ⭐⭐⭐⭐ |
| **武士刀** | 极高 | 低 | 极高 | ⭐⭐⭐⭐⭐ |

### 近战技巧

1. **推踹优先**：`空格` 键推开僵尸，创造空间
2. **地面击杀**：僵尸倒地后攻击头部，伤害更高
3. **背刺**：从背后攻击僵尸，不易被发现
4. **边退边打**：后退时攻击，保持距离
5. **利用地形**：翻越窗户/围栏，僵尸追不上

### 战斗姿态

| 姿态 | 效果 | 使用场景 |
| --- | --- | --- |
| **站立** | 正常攻击 | 普通战斗 |
| **潜行** | 不易被发现 | 偷袭、绕后 |
| **跑步** | 移动快但消耗体力 | 逃跑 |

## 远程战斗

### 枪械使用

| 枪械 | 伤害 | 噪音 | 获取难度 |
| --- | --- | --- | --- |
| **手枪** | 中 | 大 | 中 |
| **霰弹枪** | 高 | 极大 | 中 |
| **步枪** | 高 | 大 | 高 |
| **狙击枪** | 极高 | 大 | 极高 |

### 枪械注意事项

⚠️ **枪械会吸引大量僵尸！**

- 开枪前确保有足够的弹药
- 开枪后立即准备逃跑
- 霰弹枪噪音最大，但伤害也最高
- 瞄准技能影响命中率，新手容易打不中

### 推荐新手枪械策略

**前期不用枪**，近战武器足够应对少量僵尸。等熟悉游戏后再尝试枪械。

## 逃跑技巧

### 什么时候该跑？

- 僵尸数量超过 3 个
- 体力低于 50%
- 受伤/出血
- 没有好的武器
- 不确定周围环境

### 逃跑路线规划

1. **翻越围栏**：僵尸翻越速度慢，你有时间拉开距离
2. **穿过树林**：树木会阻挡僵尸，降低它们的速度
3. **进入建筑**：关门/窗可以暂时阻挡
4. **分散注意力**：扔物品或设置噪音陷阱吸引僵尸

### 翻窗/翻墙技巧

- 翻越时**不会被攻击**（动画期间无敌）
- 僵尸翻越时**会摔倒**，可以趁机攻击
- 翻越噪音会吸引附近僵尸

## 僵尸行为模式

### 僵尸类型

| 类型 | 特点 | 威胁等级 |
| --- | --- | --- |
| **普通僵尸** | 速度慢、血量低 | ⭐ |
| **奔跑僵尸** | 速度快、血量低 | ⭐⭐⭐ |
| **强壮僵尸** | 速度慢、血量高 | ⭐⭐ |
| **爬行僵尸** | 只能爬行 | ⭐ |
| **群体僵尸** | 大量聚集 | ⭐⭐⭐⭐⭐ |

### 僵尸行为

- **视觉**：正前方视野，转身可以避开
- **听觉**：枪声、爆炸声会吸引大范围僵尸
- **嗅觉**：血腥味会吸引附近僵尸
- **群体效应**：一个僵尸发现你，附近的僵尸也会跟来

## 受伤处理

### 常见伤害

| 伤害 | 处理方法 |
| --- | --- |
| **擦伤** | 绷带包扎 |
| **咬伤** | 无法治愈，只能等待死亡 |
| **抓伤** | 有概率感染，需要消毒 |
| **骨折** | 夹板固定，长时间恢复 |
| **出血** | 立即止血，绷带包扎 |

### 医疗物品

| 物品 | 用途 |
| --- | --- |
| **绷带** | 止血、包扎伤口 |
| **消毒液** | 消毒伤口，防止感染 |
| **止痛药** | 减少疼痛 |
| **抗生素** | 治疗感染 |
| **夹板** | 固定骨折 |

> ⚠️ **重要**：在 Project Zomboid 中，**咬伤 = 死亡**。被咬后只能等待感染发作，无法治愈。这是游戏的核心机制之一。
