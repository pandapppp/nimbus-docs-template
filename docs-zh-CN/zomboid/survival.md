在 Project Zomboid 中，生存是第一要务。你需要管理**食物、水源、庇护所和安全**四大要素。

## 生存优先级

```
安全 > 水源 > 食物 > 庇护所 > 长期发展
```

### 第一天：紧急生存

1. **找到武器**：厨房的菜刀、平底锅，车库的锤子、斧头
2. **收集食物**：冰箱里的易腐食品优先吃
3. **找水**：水壶、水瓶，找到就装满
4. **找庇护所**：找一个有床的房子过夜

## 食物系统

### 食物类型

| 类型 | 保存时间 | 获取方式 |
| --- | --- | --- |
| **罐头食品** | 无限期 | 搜索厨房、商店 |
| **新鲜食物** | 1-7 天 | 冰箱保存可延长 |
| **烹饪食物** | 1-3 天 | 用炉灶烹饪 |
| **种植食物** | 无限期（种子） | 耕种收获 |

### 食物获取优先级

1. **搜索房屋冰箱**：最容易获取，但会腐烂
2. **搜索罐头**：长期可靠，不需要烹饪
3. **打猎/捕鱼**：需要相关技能
4. **种植**：长期食物来源，需要种子和时间
5. **搜刮商店**：风险高但资源丰富

### 烹饪技巧

- 使用**炉灶**或**篝火**烹饪
- 烹饪可以提高食物的营养价值
- 过期食物烹饪后仍可食用（但可能生病）
- 多种食材组合可以制作更好的料理

## 水源管理

### 水源类型

| 来源 | 说明 |
| --- | --- |
| **水龙头** | 电力中断前的主要水源 |
| **水井** | 无限水源，但需要找到 |
| **雨水收集器** | Build 42 新增，长期水源 |
| **河流/湖泊** | 需要净化才能安全饮用 |
| **水壶/水瓶** | 便携式储水容器 |

### 断水应对

游戏会在**1-2周后**断水断电，你需要提前准备：

1. **收集容器**：水壶、水桶、锅、浴缸（断水前装满）
2. **建造雨水收集器**：木工技能 4 级
3. **找到水井**：部分农场有水井
4. **河水净化**：需要篝火 + 锅煮沸

## 庇护所选择

### 新手推荐庇护所

| 地点 | 优势 | 劣势 |
| --- | --- | --- |
| **郊区住宅** | 容易找到、资源丰富 | 僵尸较多 |
| **农场** | 远离城市、有耕地 | 资源较少 |
| **加油站** | 有燃料、相对安全 | 防御性差 |
| **警察局** | 有武器和弹药 | 僵尸多、难进入 |
| **仓库/工厂** | 资源丰富 | 位置可能偏僻 |

### 庇护所加固

1. **封堵入口**：用木板封住窗户和多余门
2. **设置路障**：桌子、柜子堵住门口
3. **建造围栏**：木工技能 2 级可以建造简易围栏
4. **设置陷阱**：在入口处设置噪音陷阱分散僵尸注意力

## 电力与燃料

### 断电前准备

- **收集电池**：手电筒需要电池
- **收集燃料**：加油站的汽油
- **建造发电机**：需要电气技能 + 发电机手册
- **收集蜡烛**：断电后的备用照明

### 发电机使用

1. 找到**发电机**（仓库、工厂）
2. 学习**发电机手册**（书店、邮局）
3. 将发电机放在庇护所**外面**（室内会一氧化碳中毒）
4. 加入**汽油**启动
5. 定期补充燃料

- [ ] 找到一把近战武器（菜刀、锤子、斧头）

- [ ] 找到一个安全的房子过夜
- [ ] 搜索附近的医药箱
- [ ] 找到背包增加负重
