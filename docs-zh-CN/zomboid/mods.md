## 模组安装方法

### Steam 创意工坊

1. 打开 Steam，进入 Project Zomboid 页面
2. 点击「创意工坊」标签
3. 搜索想要的模组
4. 点击「订阅」按钮
5. 启动游戏，在模组管理中启用

### 模组管理

1. 启动游戏，点击「模组」按钮
2. 在已安装列表中找到模组
3. 点击「启用」按钮
4. 重新开始游戏或加载存档

### 模组冲突处理

- **阅读模组说明**：了解兼容性信息
- **检查加载顺序**：有些模组需要特定顺序
- **逐个测试**：出现问题时逐个禁用模组排查
- **备份存档**：安装新模组前备份存档
