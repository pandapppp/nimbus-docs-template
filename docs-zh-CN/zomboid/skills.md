Project Zomboid 的技能系统是游戏的核心之一。通过**实践和阅读**来提升技能，技能等级越高，你在各方面的能力就越强。

## 技能学习机制

### 学习方式

1. **实践**：直接执行相关操作（如砍树提升斧头技能）
2. **阅读技能书**：大幅加快技能学习速度
3. **观看电视节目**：特定时间播放教学节目
4. **技能杂志**：提供特定制造配方

### 技能书系统

| 等级 | 书籍 | 效果 |
| --- | --- | --- |
| **初级** | Vol. 1 | 加速 1-2 级学习 |
| **中级** | Vol. 2 | 加速 3-4 级学习 |
| **高级** | Vol. 3 | 加速 5-6 级学习 |
| **专家** | Vol. 4 | 加速 7-8 级学习 |
| **大师** | Vol. 5 | 加速 9-10 级学习 |

> 💡 **重要**：学习技能前**先读对应的技能书**，可以节省大量时间！

## 新手技能发展路线

### 第一周：基础生存

1. **木工**：学习封窗、建造基本设施
2. **急救**：处理伤口，避免感染
3. **耕种**：开始种植食物

### 第二周：战斗提升

1. **斧头/钝器**：提升近战能力
2. **潜行**：减少被发现概率
3. **体格**：提高体力

### 第三周：长期发展

1. **电气**：建造发电机
2. **烹饪**：提高食物利用率
3. **耕种**：扩大种植规模

### 第四周：高级技能

1. **木工**：建造高级设施
2. **金属加工**：制造高级武器
3. **机械**：修理和使用车辆

3. **学校**：有教室，可能有技能书
4. **邮局**：可能有订阅的杂志

## 技能衰退

### 机制说明

- 技能等级**不会自动下降**
- 但长时间不使用某技能，**熟练度会降低**
- 重新使用时需要一定时间恢复

### 防止衰退

- **定期使用技能**：保持熟练度
- **阅读技能书**：巩固知识
- **实践操作**：通过实际使用保持技能

## 技能组合推荐

### 生存专家

```
耕种 + 烹饪 + 急救 + 木工
```

**优势**：食物自给自足，医疗能力强，可以建造和维护基地

### 战斗专家

```
斧头 + 力量 + 体格 + 潜行
```

**优势**：近战能力强，体力充沛，可以潜行接近敌人

### 制造专家

```
木工 + 电气 + 金属加工 + 机械
```

**优势**：可以建造高级设施，使用电力，修理车辆
