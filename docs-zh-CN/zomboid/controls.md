Project Zomboid 的操作方式与大多数游戏不同，采用**俯视角 + 鼠标/键盘组合**的操作模式。掌握基本操作是生存的第一步。

## 视角控制

| 操作 | 按键 |
| --- | --- |
| 旋转视角 | `Q` / `E` |
| 缩放视角 | 鼠标滚轮 |
| 重置视角 | `Home` |

> 💡 **新手提示**：建议先用默认视角（北朝上），熟悉后再尝试旋转视角。

## 移动与交互

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` |
| 跑步 | `左 Shift` + 移动 |
| 潜行 | `左 Ctrl` + 移动 |
| 互动 | `E`（开门、开窗、拾取物品） |
| 攻击 | `左键` 点击或按住 |
| 推踹 | `空格` |
| 拾取物品 | `E` 或走到物品上自动拾取 |

## 物品栏管理

| 操作 | 按键 |
| --- | --- |
| 打开物品栏 | `I` |
| 打开附近容器 | `E` 点击容器 |
| 快速转移物品 | `右键` → 转移 |
| 丢弃物品 | `右键` → 丢弃 |
| 使用物品 | `右键` → 使用 |

## 战斗操作

| 操作 | 按键 |
| --- | --- |
| 瞄准模式 | `右键` 按住 |
| 近战攻击 | `左键` |
| 推开僵尸 | `空格` |
| 切换武器 | `1`-`9` 快捷栏 |
| 装填弹药 | `R` |

## 界面说明

### 主界面元素

- **左上角**：角色状态（生命值、情绪、负重）
- **左下角**：聊天窗口（多人模式）
- **右侧**：技能面板
- **底部**：快捷栏

### 重要状态图标

| 图标 | 含义 |
| --- | --- |
| ❤️ | 生命值 |
| 🍖 | 饥饿度 |
| 💧 | 口渴度 |
| 😴 | 疲劳度 |
| 😰 | 恐惧/压力 |
| 🤢 | 疾病/中毒 |
| 🩸 | 出血/受伤 |

## 常用快捷键

| 按键 | 功能 |
| --- | --- |
| `Esc` | 暂停/菜单 |
| `F1` | 帮助 |
| `F2` | 聊天（多人） |
| `F5` | 切换天气显示 |
| `F6` | 切换树木显示 |
| `F7` | 切换建筑物显示 |
| `F11` | 截图 |
| `Ctrl` + `S` | 快速保存（单人） |

## 新手操作练习

1. **移动练习**：用 WASD 移动，Shift 跑步，感受速度差异
2. **视角练习**：用 Q/E 旋转视角，滚轮缩放
3. **拾取练习**：走进房间，E 键拾取桌上的物品
4. **战斗练习**：对着空气按空格练习推踹动作
