Project Zomboid 中每个职业有不同的起始技能和特质，决定了你在团队中的**定位和职责**。以下是各职业的详细指南。

---

## 🔧 失业者（Unemployed）

**定位**：万金油 / 自由人

| 项目 | 说明 |
| --- | --- |
| 起始技能 | 无 |
| 特质点 | +8（最多） |
| 适合玩家 | 新手、喜欢自由搭配的玩家 |

### 核心任务

- 前期自由探索，根据捡到的装备决定发展方向
- 靠特质点弥补短板（幸运、快速学习等）
- 后期根据需求转型为任何角色

### 推荐特质搭配

```
正面：幸运(-6) + 快速学习(-6) + 夜间活动者(-2)
负面：近视(+2) + 勇猛(+2) + 轻食者(+2)
```

## 🪓 伐木工（Lumberjack）

**定位**：近战输出 / 资源采集

| 项目 | 说明 |
| --- | --- |
| 起始技能 | +3 斧头、+1 力量 |
| 特质 | 能吃苦（不怕恶劣天气） |
| 适合玩家 | 喜欢近战、负责砍树建家的玩家 |

### 核心任务

- **前期**：找到斧头后战斗力极强，负责清理基地附近的僵尸
- **中期**：负责砍树采集木材，为建造提供材料
- **后期**：成为团队的主力近战输出，负责高危区域的清剿

### 优先做的事

1. 找到一把好斧头（消防斧最佳）
2. 砍树为基地建设提供木材
3. 清理基地周围僵尸
4. 负责外出搜索时的护卫工作

---

## 🔨 建筑工（Construction Worker）

**定位**：建造专家 / 基地建设

| 项目 | 说明 |
| --- | --- |
| 起始技能 | +3 木工、+1 力量 |
| 特质 | 能吃苦 |
| 适合玩家 | 喜欢建造和基地管理的玩家 |

### 核心任务

- **前期**：封窗、建造基本防御设施
- **中期**：建造围栏、陷阱、雨水收集器
- **后期**：建造高级建筑、完善基地防御体系

### 优先做的事

1. 收集锤子、钉子、锯子
2. 封堵基地所有窗户和多余入口
3. 建造木围栏和陷阱
4. 建造雨水收集器（木工 4 级）
5. 拆家具练木工技能

## 🧑‍🚒 消防员（Firefighter）

**定位**：坦克 / 负重搬运

| 项目 | 说明 |
| --- | --- |
| 起始技能 | +3 力量、+2 体格 |
| 特质 | 能吃苦、高负重 |
| 适合玩家 | 喜欢正面硬刚、负责搬运的玩家 |

### 核心任务

- **前期**：高力量近战伤害高，负责前期战斗
- **中期**：利用高负重搬运大量物资
- **后期**：团队的肉盾和搬运工

### 优先做的事

1. 找到近战武器（斧头、锤子）
2. 负责外出搜索时搬运大量物资
3. 前期清理少量僵尸
4. 利用高体格长时间作战

**定位**：远程输出 / 枪械专家

| 项目 | 说明 |
| --- | --- |
| 起始技能 | +3 瞄准、+1 射击 |
| 特质 | 无特殊负面特质 |
| 适合玩家 | 喜欢枪械战斗的玩家 |

### 核心任务

- **后期**：团队的主要枪械输出

### 优先做的事

1. 搜索警察局获取枪械弹药
2. 收集各类枪械和对应弹药

4. 负责团队的远程火力支援

## 🎮 多人游戏职业搭配

### 推荐组合（4人小队）

| 位置 | 职业 | 职责 |
| --- | --- | --- |
| **队长/输出** | 伐木工 | 近战输出、清理僵尸 |
| **建造** | 建筑工 | 建造基地、防御工事 |
| **医疗** | 护士 | 治疗伤口、管理药品 |
| **后勤** | 园丁 | 种植食物、长期规划 |

### 全能组合（2人小队）

| 位置 | 职业 | 职责 |
| --- | --- | --- |
| **战斗/建造** | 消防员 | 战斗、搬运、建造 |
| **支援/后勤** | 厨师 | 烹饪、管理、辅助 |

---

> 💡 **核心建议**：选择职业时考虑你在团队中的角色，而不是单纯追求技能数值。一个有明确职责的团队比全是战斗职业的团队更容易生存。
