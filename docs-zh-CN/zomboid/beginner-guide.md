本章是**纯新手行动指南**，按天拆解你进入游戏后该做什么。跟着走，至少能活过第一周。

## 第一天：活下来

### 早晨（6:00 - 12:00）

**目标：拿到武器 + 搜刮初始房屋**

1. **环顾四周**：出生点通常是卧室，先看窗外判断附近僵尸数量
2. **搜索房间**：
   - 厨房 → 菜刀、平底锅、食物
   - 浴室 → 绷带、消毒液、止痛药
   - 卧室 → 衣服（保暖）、背包
   - 车库 → 锤子、斧头、锯子
3. **拿好武器**：优先级 → 斧头 > 锤子 > 菜刀 > 平底锅
4. **装满水壶**：厨房水龙头右键 → 填满
5. **吃掉易腐食品**：冰箱里的新鲜食物先吃，留罐头以后

### 下午（12:00 - 18:00）

**目标：搜索邻居房屋，扩大物资储备**

1. **小心出门**：先在门口观察，确认没有僵尸再移动
2. **逐户搜索**：每次只进一栋房子，搜完再进下一栋
3. **重点收集**：
   - 🎒 背包（增加负重）
   - 🔧 工具（锤子、锯子、螺丝刀）
   - 🥫 罐头食品（不会腐烂）
   - 💊 医疗用品
   - 📖 技能书
4. **遇到僵尸**：1 个可以打，2 个考虑打，3 个以上跑

### 晚上（18:00 - 6:00）

**目标：找庇护所过夜**

1. **找一个安全的房屋**：优选独立小屋，入口少
2. **关好门窗**：按 `E` 关门，拉窗帘
3. **检查所有房间**：确认没有僵尸藏在屋里
4. **睡觉**：找床睡觉恢复体力

> ⚠️ **第一天不要冒险**，宁可少搜几栋房子，也不要死在第一天。

## 第二天：建立据点

### 目标

- 选定临时庇护所
- 封堵窗户
- 开始储备物资

### 行动清单

1. **选定庇护所**：选一个你满意的房子作为临时基地
2. **封窗**：用木板 + 钉子 + 锤子封住所有窗户
   - 只留一个出入口
3. **整理物资**：把搜来的物资分类存放
4. **继续搜索**：扩大搜索范围，往更远的房屋探索
5. **收集容器**：水桶、锅、浴缸（断水前装满水）

---

## 第三天：加固防御

### 目标

- 建造基本防御工事
- 开始种植准备
- 收集更多工具

### 行动清单

1. **建造木围栏**：需要木工 2 级（拆家具练级）
2. **设置陷阱**：钉板陷阱放在入口处
3. **找到种子**：搜索花园中心、农场
4. **找到技能书**：书店、图书馆
5. **收集木材**：砍附近的树

---

## 第四天：技能发展

### 目标

- 开始系统提升技能
- 为长期生存做准备

### 行动清单

1. **读木工技能书**：加速木工技能提升
2. **拆家具练木工**：右键家具 → 拆解
3. **开始种植**：找到土地 → 翻土 → 播种
4. **学习急救**：处理伤口避免感染
5. **收集燃料**：去加油站搜刮汽油

---

## 第五天：准备断水断电

### 目标

- 为断水断电做准备
- 建造雨水收集器
- 找到发电机

### 行动清单

1. **装满所有容器的水**：
   - 水壶、水桶、锅、浴缸都装满
   - 断水后这些就是你的水源
2. **建造雨水收集器**：需要木工 4 级
3. **找发电机**：搜索仓库、工厂
4. **找发电机手册**：书店、邮局
5. **收集电池**：手电筒需要电池

---

## 第六天：外出搜索

### 目标

- 去更远的地方搜索稀缺物资
- 扩大活动范围

### 行动清单

1. **规划路线**：看地图，标记要去的地方
2. **带上必需品**：
   - 武器
   - 食物和水
   - 绷带
   - 背包
3. **搜索高价值地点**：
   - 警察局 → 武器弹药
   - 医院 → 医疗用品
   - 超市 → 大量食物
   - 五金店 → 工具材料
4. **注意安全**：城市区域僵尸多，要特别小心

---

## 第七天：巩固基地

### 目标

- 完善基地防御
- 建立食物和水源循环
- 为长期生存做准备

### 行动清单

1. **检查并修补防御**：修复损坏的围栏/墙壁
2. **完善陷阱布局**：在基地周围设置更多陷阱
3. **检查种植情况**：给作物浇水
4. **整理物资清单**：记录缺少什么物资
5. **规划下周目标**：下一步要做什么

## 新手常犯的错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 第一天就去城市 | 僵尸太多，容易死 | 先在郊区搜刮 |
| 不封窗户就睡觉 | 半夜僵尸闯入 | 一定要封窗关门 |
| 带太多东西 | 负重过高，移动慢 | 只带必需品 |
| 和大群僵尸硬刚 | 被围攻致死 | 能跑就跑 |
| 不看身后 | 被偷袭 | 经常转身观察 |
| 不吃东西 | 饥饿导致虚弱 | 保持饥饿度正常 |
| 不喝水 | 脱水导致虚弱 | 保持口渴度正常 |
| 咬伤不处理 | 感染死亡（咬伤无解） | 咬伤 = 死亡，接受命运 |

## 时间管理技巧

### 一天的时间分配

| 时段 | 活动 | 原因 |
| --- | --- | --- |
| 6:00-12:00 | 搜索物资 | 视野好，僵尸较少 |
| 12:00-18:00 | 建造/种植 | 有足够光线 |
| 18:00-22:00 | 整理/阅读 | 天黑前回基地 |
| 22:00-6:00 | 睡觉 | 恢复体力 |

### 加速时间

- 按 `+` / `-` 键加速/减速游戏时间
- 等待、睡觉时可以加速时间
- 阅读技能书时加速时间
