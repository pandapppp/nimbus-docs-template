角色创建是 Project Zomboid 中最重要的决策之一。你的特质和职业选择将直接影响前期生存难度。

## 职业选择

游戏提供多种职业，每种有不同的起始技能和特质加成。

### 新手推荐职业

| 职业 | 优势 | 推荐理由 |
| --- | --- | --- |
| **失业者** | 无特殊加成，但有 8 点特质点 | 灵活度最高，适合自由搭配特质 |
| **建筑工人** | +3 木工、+1 力量 | 前期就能建造防御工事 |
| **消防员** | +3 力量、+2 体格 | 高力量，近战伤害高 |
| **警官** | +3 瞄准、+1 射击 | 枪械流首选 |
| **园丁** | +3 耕种 | 长期生存必备，食物来源稳定 |
| **厨师** | +3 烹饪 | 减少食物浪费，提高食物品质 |

### 新手首选：失业者

失业者没有职业加成，但有 **8 点额外特质点**，可以自由搭配强力正面特质。对于新手来说，灵活度比固定加成更重要。

## 正面特质（推荐）

这些特质消耗特质点数，但提供长期优势。

### 高优先级

| 特质 | 消耗 | 效果 | 推荐理由 |
| --- | --- | --- | --- |
| **幸运** | -6 | 提高战利品掉落率 | 降低游戏难度 |
| **强壮** | -10 | +2 力量、+2 体格 | 前期战斗力强 |
| **快速学习** | -6 | 技能学习速度 +30% | 长期收益极高 |
| **厚皮** | -8 | 减少受伤概率 | 生存能力大幅提升 |
| **夜间活动者** | -2 | 夜间效率提升 | 适合夜间行动策略 |

### 中优先级

| 特质 | 消耗 | 效果 |
| --- | --- | --- |
| **坚韧** | -5 | 减少受伤恢复时间 |
| **快手** | -4 | 提高攻击速度 |
| **健壮** | -6 | 减少生病概率 |
| **农夫** | -4 | 耕种技能 +1 |

## 负面特质（赚取特质点）

这些特质提供额外特质点数，但带来负面效果。

### 推荐选择（影响小的负面特质）

| 特质 | 获得 | 效果 | 理由 |
| --- | --- | --- | --- |
| **近视** | +2 | 远处视野模糊 | 对近战影响小 |
| **勇猛** | +2 | 不怕战斗 | 实际影响很小 |
| **早起者** | +2 | 早起困难 | 可以调整作息 |
| **夜猫子** | +2 | 晚上精神好 | 配合夜间活动者 |
| **轻食者** | +2 | 吃得少 | 减少食物需求 |
| **素食者** | +6 | 不能吃肉 | 点数多但影响大，谨慎选择 |

### 不推荐的负面特质

| 特质 | 原因 |
| --- | --- |
| **恐惧症** | 严重影响战斗，容易恐慌 |
| **抑郁** | 降低所有效率，难以消除 |
| **懦弱** | 容易恐慌逃跑，失去控制 |
| **慢学习** | 技能学习极慢，长期致命 |

## 新手推荐配置

### 方案一：稳妥型

```
职业：失业者
正面特质：幸运(-6) + 快速学习(-6) + 夜间活动者(-2)
负面特质：近视(+2) + 勇猛(+2) + 轻食者(+2)
剩余点数：2
```

**优势**：战利品多、学技能快、夜间效率高、负面影响极小

### 方案二：战斗型

```
职业：消防员
正面特质：厚皮(-8) + 快手(-4)
负面特质：近视(+2) + 勇猛(+2) + 轻食者(+2)
剩余点数：0
```

**优势**：高力量、近战强、不容易受伤、前期战斗力极强

### 方案三：生存型

```
职业：园丁
正面特质：快速学习(-6) + 健壮(-6)
负面特质：近视(+2) + 勇猛(+2) + 早起者(+2) + 夜猫子(+2)
剩余点数：4
```

**优势**：耕种起步、不容易生病、技能学习快、长期生存能力强

## 初始属性分布

创建角色时还需要分配属性点：

| 属性 | 影响 | 新手建议 |
| --- | --- | --- |
| **力量** | 近战伤害、负重 | 保持默认或 +1 |
| **体格** | 体力、耐力 | 保持默认或 +1 |
| **敏捷** | 移动速度、闪避 | 保持默认 |
| **瞄准** | 枪械精准度 | 保持默认（前期用近战） |

> 💡 **新手提示**：不要过度优化角色，Project Zomboid 的核心在于**决策和策略**，而不是属性数值。选一个你觉得有趣的配置，享受游戏过程。
