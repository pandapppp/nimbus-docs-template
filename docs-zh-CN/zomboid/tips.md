这些是老玩家总结的**实用技巧和冷知识**，很多是游戏里不会告诉你的。

## 生存小技巧

### 水和食物

| 技巧 | 说明 |
| --- | --- |
| **浴缸装水** | 断水前把浴缸装满水，能喝很久 |
| **先吃易腐食品** | 冰箱里的新鲜食物先吃，罐头留着 |
| **过期食物也能吃** | 烹饪过期食物可以吃，但可能生病 |
| **雨水收集器** | 木工 4 级可建造，长期水源 |
| **水壶随身带** | 出门一定要带水壶 |

### 移动和探索

| 技巧 | 说明 |
| --- | --- |
| **按住右键观察** | 可以360度观察周围，发现隐藏僵尸 |
| **翻窗无敌** | 翻越窗户/围栏的动画期间不会被攻击 |
| **僵尸翻窗会摔** | 僵尸翻越时会摔倒，趁机攻击 |
| **潜行偷袭** | 从背后潜行接近僵尸，一击必杀 |
| **跑步消耗体力** | 不要一直跑步，留体力应对突发 |

### 战斗技巧

| 技巧 | 说明 |
| --- | --- |
| **推踹优先** | 先推倒僵尸再攻击，更安全 |
| **地面攻击伤害高** | 僵尸倒地后攻击头部，伤害翻倍 |
| **边退边打** | 后退时攻击，保持距离 |
| **利用地形** | 翻越围栏拉开距离，僵尸追不上 |
| **分散注意力** | 扔东西吸引僵尸注意力，趁机逃跑 |

## 建造小技巧

### 基地改造

| 技巧 | 说明 |
| --- | --- |
| **封窗用木板** | 木板 + 钉子 + 锘子封窗，比家具堵门更可靠 |
| **只留一个入口** | 入口越少越好防御 |
| **设置噪音陷阱** | 放在远处，吸引僵尸离开基地 |
| **钉板陷阱** | 放在入口，僵尸踩上会受伤 |
| **床放角落** | 床放在角落，减少被偷袭的方向 |

### 木工升级

| 技巧 | 说明 |
| --- | --- |
| **拆家具练级** | 右键家具 → 拆解，免费练木工 |
| **先读技能书** | 读完技能书再练级，效率翻倍 |
| **砍树取木** | 需要斧头，木材是基础建材 |
| **钉子很重要** | 多收集钉子，建造处处需要 |

## 战斗小技巧

### 近战技巧

| 技巧 | 说明 |
| --- | --- |
| **推踹 + 攻击** | 空格推倒 → 左键攻击头部 |
| **背刺加成** | 从背后攻击伤害更高 |
| **武器耐久** | 注意武器耐久度，快坏了换一把 |
| **多带武器** | 背包里放一把备用武器 |
| **菜刀是过渡** | 菜刀伤害低、耐久差，尽快换更好的 |

### 枪械技巧

| 技巧 | 说明 |
| --- | --- |
| **枪声吸引僵尸** | 开枪会吸引大量僵尸，谨慎使用 |
| **霰弹枪最实用** | 伤害高、范围大，适合清理大群 |
| **瞄准技能影响命中** | 新手打不中很正常，多练 |
| **带够弹药** | 枪没子弹就是废铁 |
| **消音器** | 有消音器的枪更安全 |

## 物品管理技巧

### 物品搜索

| 技巧 | 说明 |
| --- | --- |
| **冰箱优先** | 新鲜食物在冰箱里，先搜冰箱 |
| **抽屉/柜子** | 很多物品在抽屉里，记得检查 |
| **床头柜** | 可能有药品、书、小物品 |
| **车库/仓库** | 工具、材料集中地 |
| **后备箱** | 汽车后备箱可能有物资 |

### 负重管理

| 技巧 | 说明 |
| --- | --- |
| **背包是必需品** | 没背包什么都拿不了 |
| **负重影响速度** | 超重会大幅降低移动速度 |
| **优先拿高价值物品** | 武器 > 食物 > 工具 > 材料 |
| **用容器运输** | 把物品放箱子里拖动，比背着快 |
| **丢弃低价值物品** | 不需要的及时丢弃 |

## 隐藏机制

### 游戏不会告诉你的事

| 机制 | 说明 |
| --- | --- |
| **咬伤 = 死亡** | 被咬无法治愈，只能等死 |
| **抓伤可能感染** | 抓伤有概率感染，不是100% |
| **尸体传染** | 触碰尸体可能生病，戴手套 |
| **天气影响** | 雨天视野差、衣服湿了会冷 |
| **噪音吸引僵尸** | 开门、跑步、战斗都会产生噪音 |
| **僵尸记忆** | 僵尸会记住你最后出现的位置 |
| **群体效应** | 一个僵尸发现你，附近的也会跟来 |
| **电力/水源会断** | 1-2周后断电断水，提前准备 |

### 冷知识

| 知识 | 说明 |
| --- | --- |
| **翻窗安全** | 翻越动画期间不会被攻击 |
| **僵尸翻窗会摔** | 利用这个机制击杀僵尸 |
| **门可以挡住僵尸** | 关门可以暂时阻挡僵尸 |
| **树木阻挡僵尸** | 树林里僵尸移动速度慢 |
| **汽车可以当武器** | 开车撞僵尸，但会损坏车辆 |
| **发电机放室外** | 室内会一氧化碳中毒 |
| **烹饪提高营养** | 烹饪后的食物营养价值更高 |
| **多种食物组合** | 不同食材组合可以制作更好的料理 |

## 新手容易踩的坑

### 致命错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 第一天去城市 | 僵尸太多，被围攻 | 先在郊区发展 |
| 不封窗就睡觉 | 半夜僵尸闯入 | 一定要封窗关门 |
| 和大群僵尸硬刚 | 被围攻致死 | 能跑就跑 |
| 不看身后 | 被偷袭 | 经常转身观察 |
| 带太多东西 | 负重过高，跑不动 | 只带必需品 |
| 发电机放室内 | 一氧化碳中毒死亡 | 放在室外 |
| 不吃不喝 | 饥饿/脱水致死 | 保持饥饿度和口渴度正常 |

### 常见误解

| 误解 | 真相 |
| --- | --- |
| 被咬可以治 | ❌ 咬伤 = 死亡，无法治愈 |
| 枪比刀好用 | ❌ 前期近战更实用，枪声吸引僵尸 |
| 跑步永远安全 | ❌ 跑步消耗体力，没体力就跑不动 |
| 基地越大越好 | ❌ 基地越大越难防御 |
| 技能自动提升 | ❌ 需要通过实践或阅读技能书 |

## 效率技巧

### 时间管理

| 技巧 | 说明 |
| --- | --- |
| **白天搜索** | 视野好，僵尸相对少 |
| **晚上建造/阅读** | 天黑后在基地内活动 |
| **加速时间** | 按 `+` 键加速，`-` 键减速 |
| **等冷却时阅读** | 休息时读技能书，不浪费时间 |
| **规划路线** | 出门前规划好要去哪里 |

### 资源管理

| 技巧 | 说明 |
| --- | --- |
| **分类存放** | 食物、医疗、工具、材料分开存放 |
| **标记位置** | 在地图上标记重要地点 |
| **定期整理** | 清理不需要的物品 |
| **备份物资** | 重要物资分开放，避免一次损失全部 |
| **记录清单** | 记录缺少什么物资，下次搜索目标明确 |
