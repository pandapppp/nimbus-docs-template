欢迎来到 **Pandas 数据分析**教程！

Pandas 是 Python 中最强大的数据分析库，广泛应用于数据科学、机器学习、数据清洗等领域。本教程将从零开始，带你掌握 Pandas 的核心功能。

## 学习路径

### 📊 基础篇

- **[Pandas 简介](/pandas/introduction/)** - 了解 Pandas 的背景、核心功能和应用场景
- **[数据结构](/pandas/data-structures/)** - 掌握 Series 和 DataFrame 的创建和操作
- **[数据读写](/pandas/io/)** - 学习读写 CSV、Excel、JSON、SQL 等格式

### 🔧 核心篇

- **[数据选择](/pandas/selection/)** - 索引、切片和条件筛选方法
- **[数据清洗](/pandas/cleaning/)** - 处理缺失值、重复值、异常值和类型转换
- **[数据处理](/pandas/processing/)** - 分组聚合、合并连接、透视表等高级操作

### 📈 应用篇

- **[数据可视化](/pandas/visualization/)** - 使用 Pandas 快速创建统计图表

## 快速开始

如果你是 Pandas 新手，建议按以下顺序学习：

1. **先看[Pandas 简介](/pandas/introduction/)**，了解 Pandas 能做什么
2. **学习[数据结构](/pandas/data-structures/)**，掌握 Series 和 DataFrame
3. **练习[数据读写](/pandas/io/)**，学会读取和保存数据
4. **掌握[数据选择](/pandas/selection/)**，高效筛选数据
5. **学习[数据清洗](/pandas/cleaning/)**，处理脏数据
6. **进阶[数据处理](/pandas/processing/)**，进行高级分析
7. **使用[数据可视化](/pandas/visualization/)**，让数据说话
