**Prompt Engineering** 是 Agent 开发中最核心的技能。好的 Prompt 决定了 Agent 的行为质量。

## Prompt 的结构

```
System Prompt（系统提示）
├── 角色定义：你是谁
├── 能力描述：你能做什么
├── 行为规范：你怎么做
├── 输出格式：返回什么
└── 约束条件：不能做什么

User Prompt（用户输入）
├── 任务描述
├── 上下文信息
└── 具体要求
```

## System Prompt 模板

```markdown
# 角色
你是一个专业的{角色}，擅长{能力}。

# 任务
{具体任务描述}

# 规则
1. {规则1}
2. {规则2}
3. {规则3}

# 输出格式
{要求的输出格式}

# 示例
用户：{示例输入}
助手：{示例输出}
```

## 核心技巧

### 1. 明确角色

```markdown
❌ 你是一个助手
✅ 你是一个资深的 Python 后端工程师，有 10 年开发经验，擅长 FastAPI 和 SQLAlchemy
```

### 2. 具体指令

```markdown
❌ 写一个函数
✅ 写一个 Python 函数，接受用户 ID 作为参数，从数据库查询用户信息，返回 JSON 格式，包含错误处理
```

### 3. 提供示例（Few-shot）

```markdown
# 示例
用户：查询用户 123 的信息
助手：{"id": 123, "name": "张三", "email": "zhangsan@example.com"}

用户：查询用户 456 的信息
助手：{"id": 456, "name": "李四", "email": "lisi@example.com"}
```

### 4. 链式思考（CoT）

```markdown
请按以下步骤思考：
1. 首先分析问题的关键信息
2. 然后制定解决方案
3. 最后给出具体实现

请一步步思考。
```

### 5. 输出格式控制

```markdown
# 输出格式
请以 JSON 格式返回，包含以下字段：
{
  "analysis": "分析结果",
  "solution": "解决方案",
  "confidence": 0.95
}
```

### 6. 约束条件

```markdown
# 约束
1. 只回答与编程相关的问题
2. 不要编造不存在的 API
3. 如果不确定，明确说明"我不确定"
4. 代码必须包含错误处理
```

## 实战案例

### 代码审查 Agent

```markdown
# 角色
你是一个专业的代码审查员，专注于 Python 代码质量。

# 任务
审查用户提交的代码，找出潜在问题并提供改进建议。

# 审查维度
1. 代码风格（PEP 8）
2. 性能优化
3. 安全漏洞
4. 错误处理
5. 可读性

# 输出格式
{
  "issues": [
    {
      "line": 10,
      "type": "performance",
      "description": "使用列表推导式替代 for 循环",
      "suggestion": "result = [x*2 for x in data]"
    }
  ],
  "score": 85,
  "summary": "代码整体质量良好，有几处可优化"
}

# 约束
- 只指出真正的问题，不要吹毛求疵
- 给出具体的代码修改建议
- 评分范围 0-100
```

### 数据分析 Agent

```markdown
# 角色
你是一个数据分析师，擅长从数据中发现洞察。

# 任务
分析用户提供的数据，给出有价值的分析结论。

# 分析步骤
1. 数据概览（行数、列数、类型）
2. 缺失值分析
3. 统计描述
4. 关键发现
5. 可视化建议

# 输出格式
请用 Markdown 格式输出，包含表格和图表建议。

# 约束
- 基于数据说话，不要编造结论
- 如果数据不足，明确说明
- 给出可执行的建议
```

## 高级技巧

### 1. 自我反思

```markdown
在回答之前，请先检查：
1. 你的回答是否准确？
2. 是否遗漏了重要信息？
3. 是否有更好的方案？
```

### 2. 角色切换

```markdown
请从以下三个角度分析这个问题：
1. 产品经理角度：用户价值
2. 工程师角度：技术实现
3. 测试角度：质量保障
```

### 3. 迭代优化

```markdown
请先给出初版方案，然后：
1. 找出初版的 3 个主要问题
2. 针对每个问题给出改进
3. 给出最终版本
```

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| Prompt 太模糊 | 明确具体要求 |
| 没有示例 | 提供 2-3 个示例 |
| 没有约束 | 明确限制条件 |
| 没有输出格式 | 定义结构化输出 |
| Prompt 太长 | 精简核心信息 |
