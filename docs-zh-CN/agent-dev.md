欢迎来到 **Agent 开发实战**教程！

AI Agent 是能自主感知环境、做出决策并执行行动的智能体。本教程将从零开始，带你掌握 Agent 开发的核心技术。

## 学习路径

### 🧠 基础篇

- **[Agent 开发概述](/agent-dev/introduction/)** - 了解 Agent 的核心概念、技术栈和发展趋势
- **[Prompt Engineering](/agent-dev/prompt-engineering/)** - 掌握 System Prompt 的核心技巧

### 🔧 核心篇

- **[Function Calling](/agent-dev/function-calling/)** - 让 Agent 调用外部工具和 API
- **[LangChain 框架](/agent-dev/langchain/)** - 使用 LangChain 构建 Agent

### 🚀 进阶篇

- **[RAG 实战](/agent-dev/rag/)** - 构建知识库问答 Agent
- **[部署上线](/agent-dev/deployment/)** - 使用 FastAPI + Docker 部署 Agent
