本章复习 Python 的六大类运算符，重点掌握整除与取余、海象运算符以及 `is` 与 `==` 的区别。

## 算术运算符

| 运算符 | 描述 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加法 | `3 + 2` | `5` |
| `-` | 减法 | `5 - 2` | `3` |
| `*` | 乘法 | `3 * 4` | `12` |
| `/` | 除法（返回 float） | `7 / 2` | `3.5` |
| `//` | 整除（向下取整） | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂运算 | `2 ** 3` | `8` |

> 注意 `//` 对负数是**向下取整**：`-7 // 2` 的结果是 `-4`，不是 `-3`。

## 比较运算符

| 运算符 | 描述 | 示例 |
| --- | --- | --- |
| `==` | 等于（值比较） | `1 == 1.0` → `True` |
| `!=` | 不等于 | `1 != 2` → `True` |
| `>` | 大于 | `3 > 2` → `True` |
| `<` | 小于 | `3 < 2` → `False` |
| `>=` | 大于等于 | `3 >= 3` → `True` |
| `<=` | 小于等于 | `2 <= 3` → `True` |

Python 支持链式比较：`0 <= x < 10` 等价于 `0 <= x and x < 10`。

## 逻辑运算符

| 运算符 | 描述 | 示例 |
| --- | --- | --- |
| `and` | 与（两者为真） | `True and False` → `False` |
| `or` | 或（其一为真） | `True or False` → `True` |
| `not` | 非（取反） | `not True` → `False` |

逻辑运算符支持**短路求值**：`and` 在第一个操作数为假时直接返回它，`or` 在第一个操作数为真时直接返回它。常用于默认值写法：`name = user_input or "匿名"`。

## 赋值运算符

```python
x = 10        # 基本赋值
x += 5        # x = x + 5 → 15
x -= 3        # x = x - 3
x *= 2        # x = x * 2
x /= 4        # x = x / 4
x //= 2       # x = x // 2
x **= 2       # x = x ** 2
x %= 2        # x = x % 2

# 海象运算符 := （Python 3.8+），赋值的同时返回值
if (n := len("hello")) > 3:
    print(f"长度为 {n}")
```

## 成员与身份运算符

| 运算符 | 描述 | 示例 |
| --- | --- | --- |
| `in` | 是否包含 | `3 in [1, 2, 3]` → `True` |
| `not in` | 是否不包含 | `4 not in [1, 2, 3]` → `True` |
| `is` | 是否同一对象（内存地址相同） | `a is None` |
| `is not` | 是否不同一对象 | `a is not None` |

### is 与 == 的区别

`==` 比较**值**是否相等，`is` 比较两个对象是否是**同一个内存对象**。

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True — 值相等
print(a is b)   # False — 两个不同的对象

# 小整数与短字符串有内部缓存，is 可能为 True，但不应依赖此行为
```

> **规范**：判断 `None` 时应使用 `is None` / `is not None`，而不是 `== None`。

## 运算符优先级

从高到低的常用顺序：`**` → 一元 `+ - not` → `* / // %` → `+ -` → 比较运算符 → `not` → `and` → `or`。拿不准时直接加括号，可读性更好。
